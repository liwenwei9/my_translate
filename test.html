📋 使用说明 / Instructions

  • 划词翻译：用鼠标选中下方的任意中文或英文文本，等待翻译浮窗出现
  • Selection Translation: Select any Chinese or English text below with your mouse and wait for the translation popup
  • 复制译文：点击翻译浮窗中的复制按钮，将译文复制到剪贴板
  • Copy Translation: Click the copy button in the translation popup to copy the translated text to clipboard

🌏 关于本项目 / About This Project

My Translate 是一个基于 FluentRead 开发的开源浏览器翻译扩展。它继承了 FluentRead 的强大功能，支持网页翻译、划词翻译、输入翻译等多种翻译模式。

This project is an open-source browser translation extension based on FluentRead. It inherits the powerful features of FluentRead, supporting multiple translation modes including web page translation, selection translation, and input translation.

✨ 主要特性 / Key Features

  • 免费翻译引擎：支持 Microsoft Translator、Google Translate、DeepLX 等免费服务，无需 API Key
  • Free Translation Engines: Supports Microsoft Translator, Google Translate, DeepLX and other free services, no API Key required
  • 划词即译：选中文本即可获得翻译结果，操作简单快捷
  • Instant Translation: Get translation results by selecting text, simple and fast
  • 双语对照：网页翻译模式下可同时显示原文和译文，方便对照阅读
  • Bilingual Display: Shows both original and translated text in web page translation mode for easy comparison
